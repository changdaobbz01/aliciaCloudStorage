# RAG 阶段 8J 生产合成表达主动探针计划

## 1. 范围

阶段 8J 在阶段 8I 识别代码发布完成后，通过专用 `RAG_ADMIN` 测试账号对生产公网识别链路执行
主动探针。2026-11-10 用户已明确授权本批模拟测试。候选全部由测试矩阵独立生成，不含真实用户名、
真实文件名、目录、账号、令牌或业务内容，因此只能标记为“授权合成表达”，不能表述为匿名真实流量。

## 2. 安全边界

```text
生产 stage                   admin-single
生产角色                     RAG_ADMIN
生产唯一动作                 FOLDER_CREATE
确认执行                     禁止
未确认任务                   立即取消
取消后步骤 attempts          必须为 0
临时 Identity 会话           必须注销
```

公网评测器只接受显式 HTTPS 的 Identity、RAG、RAG Execution 和 Cloud API 地址；只要指定外部目标，
就禁止 `-ExecuteFolderCreate`。任何基础设施失败、任务取消失败或取消后出现执行尝试都立即阻断。

## 3. 候选矩阵

```text
咨询、引用、否定与假设安全边界       6
集合选择器与名称/扩展名/前缀         7
原子移动与客户端上传反例             6
不支持能力与模糊操作边界             3
搜索与自然目录内容                   3
目录创建表达                         3
组合、闲聊与产品表达                 4
总计                                32
```

所有标签在读取生产输出前固定。偏差只作为新的候选证据记录，不得通过重复运行当前 holdout 或改标签
迎合生产结果。完成生产测量后，再决定是否进入本地修复与正式开发集晋升流程。

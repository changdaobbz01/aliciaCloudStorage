# Alicia 云盘机甲风主页素材生产计划

## 屏幕基准

- 设备像素：1080 x 2280 px
- 设备密度：440 dpi，约 2.75x
- Compose 设计基准：393 x 829 dp
- Figma 建议画布：393 x 829，按 1 Figma px = 1 dp 处理
- 位图导出建议：优先 3x，必要时保留 16-24 px 出血，避免裁切露白

## 省额度策略

- Figma MCP 主要消耗在调用次数，不是单次画多少东西。应尽量用一次脚本创建完整画布、组件、变量和样式，避免反复小改调用。
- 图像生成主要消耗在生成次数。大面积视觉素材应先一次性生成完整素材包，再局部裁切使用。
- 能用 Compose / SVG 画出来的装甲卡片、角标、底部导航、线条背景，尽量不用 AI 位图生成，后续改尺寸和颜色几乎零额度成本。
- 真正需要 AI 位图的部分只保留在高视觉冲击区域：顶部机甲头图、少量机甲装饰贴片、可选的趋势插画。

## 主页结构尺寸

- 页面左右安全边距：16 dp
- 顶部头图：186 dp，高度可在 176-198 dp 范围微调
- 搜索框：约 56 dp
- 管理员/个人空间主卡：自适应，建议控制在 150-170 dp
- 快捷入口：管理员 4 宫格，普通用户 3 宫格；普通用户不显示账号管理入口
- 指标区：2 x 2 卡片，每张约 78-92 dp
- 底部导航：约 86 dp，内容区需预留底部 padding，避免遮挡最近文件

## 当前阶段

当前优先级：只推进管理员主页设计方案。普通用户态的“账号管理”隐藏校验暂时后置，最后再处理。

最新管理员截图基准：`debug-mecha-admin-v11.png`

本轮已跟进参考图的设计元素：

- 按钮底板：搜索、查看文件切换为蓝色切角装甲按钮。
- 卡片底板：主卡、快捷入口、指标卡统一为白色装甲切角背景，补充蓝橙角标和底部发光条。
- 底部导航：管理员态改为三段式驾驶舱导航，首页选中时整块蓝色发光。
- 细节刻画：补充搜索栏分隔舱线、卡片内嵌框线、螺丝点、侧边导轨、底栏端盖和橙色排气槽。

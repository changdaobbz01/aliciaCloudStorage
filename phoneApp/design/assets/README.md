# Alicia 机甲风素材包

设计基准：393 x 829 dp，对应当前设备 1080 x 2280 px。位图建议按 3x 输出，装甲卡片、角标、底栏、数据卡优先使用 Compose/SVG 程序化绘制。

## 文件

- `alicia-mecha-vector-kit.svg`：主页通用零件素材板，可用于 Figma 导入、标注和二次拆分。
- `app/src/main/res/drawable-nodpi/alicia_mecha_header.png`：当前已进入工程的原创机甲顶部头图。

## 角色规则

- 管理员：快捷入口为全部文件、上传文件、回收站、账号管理；底部保留账号管理入口。
- 普通用户：快捷入口为全部文件、上传文件、回收站；底部使用“我的”进入个人信息，不显示“账号管理”。
